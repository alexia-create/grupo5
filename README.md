# Conversor de Unidades de Massa

Projeto desenvolvido pelo Grupo 5 como atividade de desenvolvimento colaborativo utilizando Git e GitHub.

O sistema permite converter valores entre diferentes unidades de massa diretamente no navegador, sem necessidade de servidor ou instalação de programas adicionais.

## Unidades disponíveis

O conversor trabalha com as seguintes unidades:

- Grama (g)
- Quilograma (kg)
- Miligrama (mg)
- Libra (lb)
- Onça (oz)

## Como utilizar

1. Digite o valor que deseja converter.
2. Escolha a unidade de origem.
3. Escolha a unidade de destino.
4. Clique no botão "Converter".
5. O resultado será exibido abaixo do formulário.

## Versões do projeto

### Versão 1.0.0

Primeira versão funcional do conversor.

Nesta versão, o objetivo principal foi implementar as operações de conversão entre as unidades de massa. A interface possuía uma aparência simples, sem foco em elementos visuais.

### Versão 2.0.0

Segunda versão do projeto, mantendo as funcionalidades da primeira versão e acrescentando melhorias na aparência da página.

Principais mudanças:

- Nova organização dos elementos;
- Aplicação de cores e espaçamentos;
- Campos e botão estilizados;
- Área de resultado destacada;
- Efeitos simples de interação;
- Adaptação para telas menores.

A principal diferença entre as versões 1.0.0 e 2.0.0 é a reformulação estética da interface.

## Execução

Para utilizar o projeto, basta baixar os arquivos e abrir o arquivo `index.html` em um navegador.
